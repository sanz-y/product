## 📋 ads.txt 상태 확인

구글 애드센스(Google AdSense) 승인 및 수익 손실 방지를 위한 `ads.txt`가 정상 배포되어 작동 중입니다.

```text
google.com, pub-4764608029803832, DIRECT, f08c47fec0942fa0
```

- **HTTP 응답 코드**: `200 OK`
- **Content-Type**: `text/plain; charset=utf-8`
- **배포 주소 1 (리포지토리)**: `https://sanz-y.github.io/product/ads.txt`
